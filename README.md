# sysadmin_course

Сайт-учебник курса «От железа до софта» для детей и подростков 10–17 лет. Город Памятьвиль, маскот кот Бит из семьи Байт.

## Как устроен сайт

Обычный статический сайт без сборки: HTML, CSS и JavaScript. Публикуется через GitHub Pages.

- `index.html` главная страница с картой курса и уровнями
- `lessons/NN.html` страницы уроков
- `assets/css/style.css` оформление (тёмная тема, мобильная вёрстка)
- `assets/js/course.js` программа курса: названия уроков и ссылки на готовые страницы
- `assets/js/pixel.js` пиксель-арт Бита, рисуется кодом
- `assets/js/games/` мини-игры, у каждого игрока свои случайные задания
- `sw.js` офлайн-режим: сайт сохраняется на телефон и открывается без интернета

## Как добавить урок

1. Скопировать `lessons/02.html` в `lessons/NN.html` и заменить текст.
2. В `assets/js/course.js` у урока указать `file: "lessons/NN.html"`.
3. В `sw.js` добавить новые файлы в `FILES` и поднять `VERSION`, иначе телефоны не скачают обновление.

## Как встроить домашнее задание

В Google Forms нажать «Отправить» → значок `< >` и скопировать ссылку из `src="..."`. Вставить её в `data-form` блока `data-homework` на странице урока.

## Публикация

Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`.

## Проверка локально

```sh
npx http-server -p 8080 .
```
