# sysadmin_course

Сайт-учебник курса «От железа до софта» для детей и подростков 10–17 лет. Город Памятьвиль, маскот кот Бит из семьи Байт.

## Как устроен сайт

Обычный статический сайт без сборки: HTML, CSS и JavaScript. Публикуется через GitHub Pages.

- `index.html` главная страница с картой курса и уровнями
- `lessons/NN.html` страницы уроков
- `assets/css/style.css` оформление (тёмная тема, мобильная вёрстка)
- `assets/js/course.js` программа курса: названия уроков, ссылки на страницы и отпечатки паролей
- `assets/js/forms.js` ссылки на Google Forms (этот блок выдаёт скрипт форм)
- `assets/js/pixel.js` пиксель-арт Бита, рисуется кодом
- `assets/gif/` гифки с Битом, их рисует `tools/make_gifs.py`
- `assets/js/games/engine.js` движок мини-игр, `types.js` типы игр: викторина, пары, сортировка, биты
- `assets/js/content/lessonNN.js` задания для игр конкретного урока
- `sw.js` офлайн-режим: сайт сохраняется на телефон и открывается без интернета
- `tools/password.html` считает отпечаток пароля к уроку
- `tools/google-forms.gs` скрипт Google Apps Script, который создаёт формы ДЗ и тестов

## Как добавить урок

1. Скопировать `lessons/03.html` в `lessons/NN.html` и заменить текст. Теоретические блоки помечены `data-locked`, игры открыты всегда.
2. Создать `assets/js/content/lessonNN.js` с играми (образец в `lesson03.js`) и подключить его внизу страницы.
3. В `assets/js/course.js` у урока указать `file: "lessons/NN.html"` и `pass` (отпечаток из `tools/password.html`).
4. В `sw.js` добавить новые файлы в `FILES` и поднять `VERSION`, иначе телефоны не скачают обновление.

## Пароли к урокам

Мини-игры открыты всем, а теория и ДЗ открываются паролем, который учитель называет в конце урока. Регистр, пробелы и дефисы не важны, ё = е. Пароль учителя открывает все уроки сразу. Это школьный замок: текст лежит в странице, просто скрыт.

Сменить пароль: открыть `tools/password.html`, ввести новый пароль, вставить отпечаток в `pass` урока в `course.js`.

## Домашние задания и тесты

1. Открыть https://script.google.com → «Новый проект», вставить `tools/google-forms.gs`, запустить `createAll`.
2. В Google Диске появится таблица «Памятьвиль: результаты». С листа «Ссылки» скопировать блок `window.FORMS = {...}` в `assets/js/forms.js`.
3. Ответы приходят в ту же таблицу, по листу на форму.
