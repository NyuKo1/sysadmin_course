# sysadmin_course

Сайт-учебник курса «От железа до софта» для детей и подростков 10–17 лет. Город Памятьвиль, маскот кот Бит из семьи Байт.

## Как устроен сайт

Обычный статический сайт без сборки: HTML, CSS и JavaScript. Публикуется через GitHub Pages.

- `index.html` главная страница с картой курса и уровнями
- `lessons/NN.html` страницы уроков
- `assets/css/style.css` оформление (тёмная тема, мобильная вёрстка)
- `assets/js/course.js` программа курса: названия уроков, ссылки на страницы и отпечатки паролей
- `assets/js/forms.js` ссылки на Google Forms (этот блок выдаёт скрипт форм)
- `assets/js/pixel.js` пиксель-арт Бита, рисуется кодом
- `assets/gif/` гифки и анимированные мемы, их рисует `tools/make_gifs.py` (список в `assets/gif/README.md`)
- `assets/js/story.js` мультсценки, сюжет месяца в `assets/js/content/storyNN.js`, просмотр всех сцен: `tools/story-preview.html`
- `assets/js/games/engine.js` движок мини-игр, `types.js` типы игр: викторина, пары, сортировка, биты
- `assets/js/content/lessonNN.js` задания для игр конкретного урока
- `sw.js` офлайн-режим: сайт сохраняется на телефон и открывается без интернета
- `tools/password.html` считает отпечаток пароля к уроку
- `tools/google-forms.gs` скрипт Google Apps Script, который создаёт формы ДЗ и тестов

## Как добавить урок

1. Скопировать `lessons/03.html` в `lessons/NN.html` и заменить текст. Блоки после первой игры помечены `data-stage`.
2. Создать `assets/js/content/lessonNN.js` с играми (образец в `lesson03.js`) и подключить его внизу страницы.
3. В `assets/js/course.js` у урока указать `file: "lessons/NN.html"` и `pass` (отпечаток из `tools/password.html`).
4. В `sw.js` добавить новые файлы в `FILES` и поднять `VERSION`, иначе телефоны не скачают обновление.

## Как проходят урок

Урок идёт по цепочке: теория, игра, следующая теория. Блоки с `data-stage="1"`, `"2"`, `"3"` открываются, когда выиграна игра из предыдущего блока. Открытое запоминается на телефоне, так что пройденное можно перечитать. Пароль, который учитель говорит в конце урока, открывает весь урок сразу. Регистр, пробелы и дефисы не важны, ё = е. Пароль учителя открывает все уроки и страницы учителя. Это школьный замок: текст лежит в странице, просто скрыт.

Пароли: `tools/password.html`. После входа паролем учителя там видны пароли всех уроков, и можно сделать новый: страница выдаст строку `pass` и `secret` для урока в `course.js`. `pass` это отпечаток для проверки, `secret` это пароль, зашифрованный паролем учителя.

## Лекции для учителя

`teacher/index.html` и `teacher/NN.html`: полный текст лекции к каждому уроку, открывается только паролем учителя.

## Домашние задания и тесты

1. Открыть https://script.google.com → «Новый проект», вставить `tools/google-forms.gs`, запустить `createAll`.
2. В Google Диске появится таблица «Памятьвиль: результаты». С листа «Ссылки» скопировать блок `window.FORMS = {...}` в `assets/js/forms.js`.
3. Ответы приходят в ту же таблицу, по листу на форму.
4. Новые формы `hw-04b` (сложное ДЗ к уроку 4) и `exam-m1` (экзамен месяца 1) спрашивают фамилию и имя, класс и email родителя. Старые формы `hw-02`, `hw-03`, `hw-04`, `test-m1` не меняются.
5. Развёрнутые ответы учитель оценивает в самой форме («Ответы» → «Вопрос»). Потом `refreshGrades` собирает лист «Оценки» (баллы, %, оценка 5/4/3/2 по порогам `GRADES` в начале скрипта), учитель ставит галочку «Проверил учитель», и `sendGrades` отправляет родителям письма с его Google-аккаунта (каждое один раз). Меню «Памятьвиль» в таблице появляется, если вставить скрипт через «Расширения» → «Apps Script» самой таблицы.
