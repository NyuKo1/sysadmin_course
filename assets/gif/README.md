# Гифки Памятьвиля

Все файлы рисует `tools/make_gifs.py` (Pillow) из спрайтов `assets/js/pixel.js`. Перегенерировать: `python3 tools/make_gifs.py`. Пиксели увеличены в 4 раза без сглаживания.
