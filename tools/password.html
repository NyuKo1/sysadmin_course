Почему два поля. pass это отпечаток: по нему сайт проверяет пароль, но обратно его не развернуть. secret это тот же пароль, зашифрованный паролем учителя: без пароля учителя его не прочитать. Это школьный замок, а не банковская защита, но списать пароль из кода страницы ученику уже не получится.
